## Como instalar

| Arquivo | Para quem |
|---|---|
| `GestaoBarbearia_..._x64-setup.exe` | **Instalador** (recomendado). Instala no computador e recebe atualizações automáticas. |
| `GestaoBarbearia_..._portatil.zip` | **Portátil**: extraia e use sem instalar, inclusive em pendrive. Avisa quando há versão nova. |
| `SHA256SUMS.txt` | Códigos para conferir que o arquivo baixado é o original. |
| `latest.json` | Usado pelo próprio programa para se atualizar. Não precisa baixar. |

### "O Windows protegeu o computador"

O programa ainda não tem certificado digital pago, então o Windows mostra esse aviso
para programas novos. Clique em **Mais informações** e depois em **Executar assim mesmo**.
Baixe sempre desta página.

### Requisitos

Windows 10 ou 11 (64 bits). Funciona sem internet; a internet só é usada para o
WhatsApp e para verificar atualizações.

## Novidades da 0.3.0

- **Backup automático diário**, mantendo as 14 cópias mais recentes, com aviso no Início
  quando o último backup estiver antigo.
- **WhatsApp sem cadastro na Meta**: os botões abrem o WhatsApp com a mensagem pronta.
- **Atualização automática** (instalador) e aviso de versão nova (portátil).
- **Visual novo** com tema claro (o escuro continua em Configurações) e valores no formato
  R$ 1.500,00.
- **Segurança**: o token da API do WhatsApp fica no Cofre de Credenciais do Windows, fora
  dos backups.
- Correções: edição de despesa, restauração de backup com falha, status da agenda,
  tela de Relatórios, textos e mensagens.
